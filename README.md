# 🛒 Jumia Product Analysis

## 📌 Overview

An Excel data analysis project exploring Jumia product prices, discounts, customer ratings, and reviews to identify trends and customer engagement patterns.

## 🛠️ Tools

* Microsoft Excel
* Data Analysis
* Data Visualization
* Dashboard Development

## 📊 Key Analysis

* Product discount analysis
* Customer ratings and reviews
* Top 10 discounted products
* Highest- and lowest-rated products
* Discount percentages vs. customer engagement
* Interactive Excel dashboard

## 💡 Key Objectives

* Identify pricing and discount trends.
* Understand customer ratings and engagement.
* Generate insights to support data-driven decisions.
